Baseline commit for report: `3b0e2807`.

## 1. Experiment performed and limits

Synthetic Latin + numeric-confusable + kana glyphs:
- Fonts: DejaVuSans-Bold, P052-Roman, URWGothic-Demi.
- Glyph set: `a g 8 0 6 が パ 4`.
- Sizes implicitly ~9 pt at 300 DPI.
- Observations generated directly from rendered source via fractional placement, blur, noise and ink variation.
- All comparisons are rasterized medians at 300 DPI against `source >= 0.5`;
  shape geometry is measured as pixel coverage (IoU) plus boundary distance.
- Oracle, unaligned and estimated outputs compared in a common coordinate frame.
- No OCR labels are used for reconstruction; no production code or thresholds touched.

Limitations:
- Rasterized evaluation, not full vector polygon distance.
- Median fusion only; no C robust alternatives in this pass.
- Estimated registration still fails on most groups.
- N limited to 1,2,4,8; no N=16/32 cross-family generalization yet.

## 4. Interpretation and example evidence

- D (oracle-aligned fusion) improves boundary error over A and over C at every N>1
  (`N=8`: D 0.216 vs C 0.281).
- C (unaligned fusion) often worsens alignment-stroke error because unregistered
  translations average into thicker soup.
- B medoid has surprisingly poor boundaries at N>=4 in this diagnostic, showing
  selecting a good clear image is not enough.
- E estimated arm barely improves and occasionally fails alignment entirely
  (registration median 2.10 px, max 35.05 px); this isolates the estimator/register
  problem.

Improving case:
- `work/m1c_r3/diag4/DejaVuSans-Bold.ttf_a_N4_diag4_.../D_oracle_mask.png`
  shows clear stroke consolidation for repeated `a`.

Failing case:
- Same directory `E_estimated_mask.png`: blurred/furried strokes due to remaining
  phase error and occasional wild shifts.

## 5. Remaining threats to validity

- Registration estimator assumes observations share an obvious reference and fails
  for some glyphs (`max disp 35 px`, clearly catastrophic).
- Pixelized ground truth and threshold 0.35 may bias medoid selection.
- No vector-polygon distance, no variance real obstacle scaling yet.
- No anti-leak formal oracle (ground truth used only for evaluator comparison).
- Bootstrap only aggregates by observation group, not independent font/glyph trials.
