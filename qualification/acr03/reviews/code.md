# ACR03 independent code and evidence review

**Scope:** Fixed ACR03 prototype/comparison scripts and saved local outputs only. Production code was not changed. No holdout was accessed.

## Findings

- **No blocker found in the fixed five-case research comparison.** The two candidate arms are derivative-only. The inferred arm uses source-rendered colour/chroma and residual support; authoring masks appear only in explicitly named oracle outputs for the controlled logo/annotation. No pristine text or paper enters inference. Comparison uses fixed source-coordinate crops without registration. The chosen ACR01/source pages have matching page canvases, CropBox=MediaBox, rotation 0 and default UserUnit.
- **Typography ownership works for the exercised pages.** `font_boxes` maps each visible one-CID `Tj` through its embedded TrueType outline, CIDToGIDMap, text matrix and physical placement; intersecting vector shows are retained as invisible text while the source crop supplies visible colour. The inspected target pages use one 2-byte CID and a fresh `Tm` per show, only fill (`Tr 0`) for visible glyphs; no `TJ`, `Tz`, `Tc`, `Tw`, `Ts`, rotated text matrix, or Form text was present. The logo output suppresses the dark ACR01 `S` paint and recovers the blue source glyph. Poppler/PDFium text extraction and embedded font/ToUnicode stream hashes matched the baselines in the saved logo, annotation, seal and full 13-page financial candidates.
- **Mapping and masks are coherent on these page geometries.** The `.24 pt/pixel` mapping corresponds to the 300-DPI raster pixel grid. Source and non-font residual render to equal canvases; the target pages have zero-origin, unrotated MediaBoxes. B's 1-bit DeviceGray soft masks use the same tile bounds as their colour images and were rendered by both PDFium and Poppler. The selected-case comparison sheets show no new crop displacement. This does not qualify arbitrary page origins, UserUnit, CropBox differences, rotated text, or multi-CID text shows; the prototype should remain restricted to the tested ACR01-style pages unless it adds guards for those inputs.
- **Candidate A has a narrow visual pass, with a size cost.** The independent visual review found the logo, crossing annotation/rules, red seal and inspected financial values readable and clean. The seal-page A PDF grows from 5,114,421 to 6,045,921 bytes; A is not a general compression improvement. The selected-page review does not establish a full-document historical quality/size benefit.
- **Candidate B's full financial byte result is real but modest and not a glyph-reconstruction result.** The saved complete 13-page PDF is 8,442,537 bytes versus the 9,018,954-byte baseline (576,417 bytes, 6.39% smaller). All 13 rows report `paper_eligible=true`, zero unknown pixels outside object rectangles, and no fallback. In those pages, object count and transferred visible glyph count are both zero: the saving comes from the paper/tile raster representation, not improved font coverage. Text and font stream equality checks pass. Visual comparisons cover selected areas, especially page 10; they are not an exhaustive visual review of all 13 pages.
- **The unknown-paper fallback has a path inconsistency.** In `build`, the unsupported-paper early return is conditional on `shared is not None`. The standalone shaded-page `--case shade --representation masked` run therefore emits a candidate despite 26.4% unknown pixels, while the shared-document path would skip that page. This makes the standalone shaded output a valid negative example, but it does not verify the claimed fallback on a complete historical document. Do not claim that the shaded case is safely handled by fallback until the guard is exercised in the shared-document path or the standalone path returns an explicit fallback result too.
- **Reproducibility binding is incomplete.** Per-case `result.json` stores candidate hashes and byte sizes, but not source/baseline hashes or the prototype/comparison script hashes. The saved PDFs and input artifacts make the experiment inspectable, but the metrics are not fully bound to exact source/script revisions. Add a small run manifest before treating the numeric results as independently reproducible.

## Decision

Candidate A is the stronger selected-case fidelity result, but historical growth defeats a general compression recommendation. Candidate B's full financial saving is measurable and semantically preserves existing text, but 6.39% is modest, its selected visual coverage is incomplete, and its shaded-page fallback is not yet qualified in a full document. Keep both as research evidence; neither supports general product integration on these results alone.
