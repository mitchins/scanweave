## Review measurements

All 54 patches satisfy `patch & ~owned == 0`; no patch intersects the reconstructed recorded artwork foreground or the frozen reference ink within another OCR symbol’s box. Those checks are source-pixel measurements, not a statement about renderer antialiasing or a substitute for visual review. Of the 54 glyphs, 53 have at least one source-reference ghost-ink pixel by the specified one-pixel-touch rule, and 36 have at least one source-reference pixel inside the patch but outside the vector midpoint mask. The halo boundary ring is present for every glyph; mean absolute luminance differences range from 9.59 to 16.39, and the per-glyph maximum ranges from 22.67 to 36.31. These are flags and measurements, **not decisions**. The definition of ghost ink is a frozen reference-mask proxy and may include adjacent marks; the panels expose the pixels in red. Cyan denotes under-replaced reference pixels, and magenta denotes detected foreign ink.

At 300 DPI, totals summed across the 54 independent trials for changed renderer pixels outside the mapped exact owned mask are PDFium 1,576, Poppler 4,597 and MuPDF 3,510. Pixels outside a further two-render-pixel diagnostic envelope total 3, 72 and 3 respectively, spanning 20 trials. The envelope does not grant source ownership and these differences have **not** been classified as harmless; each record contains the per-renderer count and a neutral flag for review. PDFium produces 1738×2355 pages here; Poppler and MuPDF produce 1737×2354, so the source ownership mask is mapped to each renderer’s page dimensions using nearest-neighbour sampling for the renderer-only count. Physical patch containment is checked separately at canonical source resolution without that mapping.

One proposal, 43 (`w000024s0000`), has a proposal bbox beginning at x=1167 and its saved same-symbol owner bbox beginning at x=1166. The owner bbox contains the proposal bbox; the full saved mask, not an enlarged or invented mask, is used. Both bboxes and the mismatch flag are in its row. Frozen HVC-41D scores are copied unchanged from `2a10fc3`; actual isolated-trial font scores are recorded alongside them. The latter differ slightly for proposals 98 and 236, with both still passing the unchanged numerical bounds. No threshold or proposal pool was changed.

The 54-trial diagnostic font-mask union intersects 10,285 pixels of the 208,768-pixel reference proxy. That is **not** verified emitted coverage, and it differs from the owner’s earlier 9,930-pixel pre-review ceiling. The definitions or source of that discrepancy have not been reconciled; it must be resolved before using the count in a coverage claim. It is not authorization to expand the proposal pool or target. See [phase1-summary.json](phase1-summary.json).

## Source and OCR controls

The input PDF hash, p1 canonical source-pixel and decoded-RGB hashes, raster dimensions, all hOCR hashes, #39 completed-PDF hash and frozen validator hash are checked before diagnostic generation. The frozen hOCR sidecar is mandatory. A failing Tesseract stub was first in PATH and was not invoked; no new OCR was run. [OCR-lock tests](ocr-lock-tests.json) show fail-closed behavior for a missing sidecar and altered PDF hash, dimensions, pixel hash, decoded RGB hash and hOCR hash. The earlier HVC-41B accidental ordinary CLI invocation remains documented in [HVC-41D](../hvc41d/REPORT.md).

For foreign artwork checks, the p1 foreground is reconstructed from the recorded interior paper and the existing luminance distance threshold, with eight-connected components. All 683 recorded artwork entries have the expected component IDs, bounding boxes and pixel counts ([artwork validation](artwork-validation.json)); there was no saved full mask for every artwork component for an independent bitwise comparison. Other-symbol foreground uses the frozen reference mask within other OCR boxes, so overlaps are conservative and OCR-box limitations remain. No calibration or identity decision is inferred from these measurements.

The first trial-generation attempt stopped before completing the first record because Poppler’s raster dimensions differed by one pixel from PDFium’s. The renderer-coordinate mapping was corrected. A subsequent attempt stopped at proposal 43’s contained-box discrepancy described above; the actual saved unit mask was retained. The finished run then generated all 54 records with the same frozen numerical bounds. These were diagnostic retries, not a final p1 assembly or a change to source ownership.
