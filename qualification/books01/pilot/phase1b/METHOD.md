# Phase 1b methods and limitations

Run only on the existing six-page pilot. `REGISTRATION.md` specifies the fixed acceptance rule. `register.py` estimates one output-to-source global similarity per page, row, renderer and DPI with SIFT features; it either accepts that fit or an exact pixel identity. The recorded rotation and translation describe this inverse mapping. Residuals are expressed at 150-DPI equivalent. It writes new aligned renders, preserving the native renders. No local warp is used. Nonidentity transforms use bicubic interpolation and white outside the output; interpolation itself affects scores. `page_boxes.py` records page boxes and the fraction of a 128×128 source grid outside the inverse-mapped output. This is a coverage warning, not proof of actual content loss. Region metrics retain native and aligned results; see `results/phase1b/scorecard.json` for every renderer and DPI.

`line_ocr.py` groups sequential PDFium character boxes by line breaks and geometry, maps them to the source frame with the PDFium registration, and pairs boxes to GT using one-to-one maximum-weight assignment with bounding-box IoU ≥ 0.2. It reports unmatched GT and extra output boxes, but grouping can split, merge or mispair lines, so these counts are not established missing or extra lines. Same-GT comparisons independently match both frozen hOCR and PDF text to the identical set of GT lines. FineBooks uses only single-line TextRegion proxies; other FineBooks regions are excluded from line scores. Search is restricted to sampled GT words present as exact reading-normalised frozen-hOCR tokens; PDFium search itself is case-insensitive literal search. Existing document CER/WER and the full search/control results remain in the scorecard.

`join_review.py` joins the 66 previous blind crop verdicts with the previous key. All verdicts and new observations are **AI-assessed, provisional (not human-adjudicated)**. `calibrate.py` scores aligned crops, requiring source contrast and real source ink rather than a size floor. It reports raw scores and stratifies by minimum box dimension below 10 source pixels. Thresholds are fit on the same small reference sample, and unsupported classes cannot yield meaningful precision or recall. Illustration colour is scoped to annotated graphics, not text. `controls.py` selects one fresh non-overlapping word candidate per page and output with a fixed seed; the local contact sheets were assessed by an AI with row identities visible, so they are neither human verdicts nor a blind validation set. `triage_all.py` saves all raw scores locally, and summaries are committed. Detector flags are suspicions only. The human panel provides a separate fresh blind presentation; its key stays local.

Reproducibility: paths and versions come from the Phase 1 manifest and scripts; run the scripts using the prepared isolated Python, with `TMPDIR` under `$B/tmp`. No converter, OCR engine, Wine or Acrobat was run in this phase. Phase 1 source DPI uncertainty, particularly Benner's low-confidence 300 DPI, is unchanged. Adobe means **Acrobat default OCR language (not matched); no Fraktur support; page straightened (deskew)**.
