# Six-page pilot harness

All programs read `pilot_6` from the frozen manifest. They require the prepared qualification venv, baseline binary and model directory; export `TMPDIR=/data/coding/scanweave/work/books01/tmp` and `TESSDATA_PREFIX=/data/coding/scanweave/work/books01/tessdata_best`. Run Python with the prepared venv's `python -I`. Outputs and temporary files are under `/data/coding/scanweave/work/books01`, while small result JSONs are written here. Existing Acrobat outputs are read only.

The implementation order is `versions.py`, `freeze_ocr.py`, `run.py`, `negative_shim.py`, `path_equivalence.py`, `text_metrics.py`, `object_sizes.py`, `search_layout.py`, `alignment.py`, `extraction_diagnostics.py`, `render.py`, `visual.py`, `triage.py`, `adobe_repeat.py`, `performance.py`, `annotate.py`, and `make_report.py`. Compile `edit.c` into `$B/pilot/edit.so` with `cc -O2 -fPIC -shared` before text scoring. `verify_strict_runs.py` rechecks the strict shim, `retry_ocrmypdf.py` handles the documented config failure, `rerender_poppler.py` and `repair_renders.py` document the CropBox rerender and interrupted-file recovery, and `refreeze_psm6.py` documents the exact retry argument-order recheck. Per-command GNU time files and logs remain local. Wrap measurement stages in `/usr/bin/time -v` to capture their CPU and peak RSS; see `performance.py` for the expected time-file names.

Never commit `$B` files, GT or hOCR text, PDF or image data, raw per-row triage scores, or the blind key. `blind-index.json` is local to the pack and contains no row mapping; the separate local key is necessary for later adjudication. Random blind labels are generated with operating-system randomness and will differ on regeneration.
